# Cписок требований, которым должны удовлетворить внешние интеграции

1. Транспортное шифрование TLS 1.2+ (Transport Layer Security)
2. Журналирование всех взаимодействий с внешними системами (аутентификация, авторизация, чтение и изменение данных)
3. Монитрониг аномального взаимодействия (нетиповое повышение трафика, ошибки) с оповещением службы ИБ
4. Хранение секретов (логинов и паролей) для доступа к внешним системам в защищенном хранилище (например Hashicorp Vault)
5. Передача в сторонние системы минимально-необходимого набора данных
7. Внедрение системы DLP (Data Loss Prevention)
9. Аутентификация и авторизация с использованием протоколо OIDC / OAuth 2 и зашифрованных JWT токенов, использование сертификатов.
10. При передаче чувствительных данных применение шифрования и подписи.
11. Хранение ПДн в зашифрованном виде.
12. Взаимодействие только с поставщиками с поддержкой функции отзыва ПДн.
